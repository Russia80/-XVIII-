# Meridian: XVIII Century
Историческая RPG о консенсусе человека и машины. Россия, 1764 год.

Вы — наследник тайного протокола **Meridian-0**. Ваш путь лежит от деревни Заозерье до императорского двора. Каждое решение проверяется системой через три столпа: Род, Честь и Интерес.

## 🏛️ Три столпа (Игровой протокол)
Ваша репутация — это данные в глобальной сети Меридиан.
*   **Род (`Dynastic_Reputation`)**: Династические связи.
*   **Честь (`Social_Legitimacy`)**: Доверие общества.
*   **Интерес (`Pragmatic_Capital`)**: Влияние и ресурсы.
