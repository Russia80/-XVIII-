# Meridian: XVIII Century

Историческая RPG с консенсус-протоколом. Россия, 1764 год.

Вы — наследник тайного протокола *Meridian-0*. Путь от глухой деревни Заозерье до императорского двора Санкт-Петербурга.

## 🏛️ Три столпа (Игровая система)
Ваша репутация проверяется протоколом при каждом важном решении:
*   **Род (`Dynastic_Reputation`)**: Наследие семьи.
*   **Честь (`Social_Legitimacy`)**: Доверие общества.
*   **Интерес (`Pragmatic_Capital`)**: Ресурс влияния.
