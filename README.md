# Meridian: XVIII Century
Историческая RPG с консенсус-протоколом. Россия, 1764 год.

Вы — наследник тайного протокола *Meridian-0*. Путь от глухой деревни Заозерье до императорского двора Санкт-Петербурга и геополитических столиц мира. Игра исследует конфликт между человеческим духом (Род, Честь) и холодной логикой машины (Интерес/Протокол).

## 🏛️ Три столпа (Игровая система)
Ваша репутация проверяется протоколом при каждом важном решении:
*   **Род (`Dynastic_Reputation`)**: Наследие семьи. Открывает закрытые двери, но требует соблюдения традиций.
*   **Честь (`Social_Legitimacy`)**: Доверие общества. От крестьянской общины до гвардейских полков.
*   **Интерес (`Pragmatic_Capital`)**: Ресурс влияния. Деньги, связи, власть.
